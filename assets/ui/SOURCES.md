# UI asset sources

## Tiny RPG - Dark Dwellers GUI

- Creator: Gabriel "tiopalada" Lima
- Source: https://opengameart.org/content/tiny-rpg-dark-dwellers-gui
- Original project page: https://tiopalada.itch.io/tiny-rpg---dark-dwellers-gui
- License: CC0 1.0 Universal (public domain dedication)
- License text: https://creativecommons.org/publicdomain/zero/1.0/
- Local files: `dark_dwellers/`

The complete 159 KB source archive is kept here so future UI screens can reuse
the matching panels, headers, slot states, equipment silhouettes, bars, and
cursors. The original `README.html` is included unchanged.

## FiveM Inventory Icons — Pixel Art

- Creator: SwisserDev
- Source: https://github.com/SwisserDev/fivem-icons-pixel
- Release: version 1.0
- License: CC0 1.0 Universal (public domain dedication)
- Local files: `item_icons/`

The upstream pack contains 1,235 normalized icons in one pixel-art style. This
project includes only the 30 100×100 WebP files mapped to the first-iteration
item catalog. Some fictional items use the nearest visual analogue from the
same set. The upstream `LICENSE` is retained as `item_icons/LICENSE.txt`.
